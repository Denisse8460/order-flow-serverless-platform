# OrderFlow
Resilient serverless order processing platform built withb Python and AWS.

# Objetive

OrderFlow is an event-driven backend system designed to process e-commerce orders reliably and efficiently.

The project demonstrates software engineering concepts including:
-Object-oriented programming
-Data structures and algorithms
-REST APIs
-Even-driven architecture
-Serverless computing
-NoSQL databases
-Fault tolerance 
-Automated testing
CI/CD
-Monitoring and observability

# Tech Stack

-Python
-AWS Lambda
-Amazon API Gateway
-Amazon DynamoDB
-Amazon SQS
-Amazon CloudWatch
-AWS SAM
-Pytest
-Github Actions
